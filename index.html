This browser can't talk to USB devices

VKB Scope uses WebHID, which Firefox and Safari don't implement. Open this page in a Chromium-based browser — Chrome, Chromium, Edge, Brave or Vivaldi — and it'll work.

On Linux you may also need permission to read the device. For VKB gear, create /etc/udev/rules.d/99-vkb.rules containing KERNEL=="hidraw*", ATTRS{idVendor}=="231d", MODE="0660", TAG+="uaccess" then run sudo udevadm control --reload-rules && sudo udevadm trigger.
